QR Code Maker em Python lek!

Extremamente simples, MAS funciona hehehehehe

Se liga então:

Funcionalidades
- Interface gráfica construída com **Tkinter**.
- Processamento e manipulação de imagem com a biblioteca **Pillow**.
- Validação de entrada de dados com tratamento de exceções (`try/except`).
- Arquitetura modular (`generator.py`) e interface (`gui.py`).

Tecnologias Utilizadas
- [Python 3](https://www.python.org/)
- [Tkinter](https://docs.python.org/3/library/tkinter.html)
- [qrcode](https://pypi.org/project/qrcode/)
- [Pillow](https://pypi.org/project/Pillow/)
